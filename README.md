## 评分方法 / Scoring
- 效果 Effectiveness、价值 Value、易用 Ease、成本 Cost（越便宜分越高 / higher = cheaper），各 1–10；总分 = 四项平均。
- 测试级别如实标注：实测 = 本机实际运行；部分实测 = 安装/启动到一半；实测(结构) = 校验文件与格式；仅评审 = 只读文档。
- Test level is reported honestly: tested / partially tested / structure-checked / README-only review.
- 禁用项不打分 / Banned tools are not scored.

## 环境 / Environment
Linux 沙盒，无 Docker、无数据库、无 GPU、不使用任何密钥 / Linux sandbox, no Docker, DB, GPU or secrets.
